### <div align="center">I'm Emrah — founder & product engineer 👨‍💻 building consumer platforms in Montenegro, Kosovo and the USA 🚀</div>

- 🚕 Building **[MonteGO](https://montego.app)** — a full ride-hailing ecosystem running **across all of Montenegro**: passenger & driver apps, live dispatch, scheduled rides & transfers, bidding marketplace, 3D Secure card payments and an AI support assistant that speaks the customer's language.

- 🏗️ Currently migrating the platform backend to **Go + PostgreSQL** for the next stage of scale.

- 🤖 Running AI-assisted operations: multilingual support chat, automated ride auditing, smart notifications.
